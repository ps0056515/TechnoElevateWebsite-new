### Problem

MnDOT needed a secure, scalable backend managing the full E-ZPass tolling lifecycle - accurate transaction posting, real-time balance updates, violation detection, dispute handling and cross-team coordination.

### Solution

Built ETBOS to automate toll transaction processing across Express, HOV and automated lane types, with rule-based violation detection and full end-to-end dispute resolution support.

### Tech stack

- Java
- Microservices
- Rules Engine
