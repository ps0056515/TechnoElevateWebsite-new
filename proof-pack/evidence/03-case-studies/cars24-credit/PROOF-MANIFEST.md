### Problem

Heavy operating costs from third-party credit scoring combined with low approval rates for new-to-credit users - CARS24 needed in-house fintech underwriting capability using alternative data.

### Solution

Built proprietary fintech microservices that ingest banking and alternative data (SMS transaction history) to score applicants in-house, fully eliminating external API cost dependency.

### Tech stack

- Microservices
- Python
- ML Scoring Models
- Alternative Data Pipelines
