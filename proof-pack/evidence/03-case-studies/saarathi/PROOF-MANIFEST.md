### Problem
Used-car loan origination through agents was slow, inconsistent and hard to compliance-check. Agents needed one unified app for lead creation, KYC, CIBIL checks and full loan origination.

### Solution
Delivered Saarathi — a next-generation lending platform with workflow engine, attribute-based access control (ABAC), real-time CIBIL checks, document management and negotiation tooling.

### Tech stack
- Microservices
- ABAC
- CIBIL API
- Workflow Engine
