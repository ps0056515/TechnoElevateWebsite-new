### Problem
Industrial operations had rich raw data from sensors and devices but no unified platform to ingest, analyze, and visualize it — no ML-driven insights, no real-time dashboards, no alerting.

### Solution
Built an interactive IIoT analytics platform — live sensor ingestion, statistical analysis, ML models, real-time dashboards, KPI reports, multi-threshold alerting, and role-based access management.

### Tech stack
- Node.js
- Angular
- MongoDB
- AWS
