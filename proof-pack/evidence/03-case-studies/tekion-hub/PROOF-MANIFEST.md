### Problem

OEMs run a heterogeneous mix of ERP, CRM, inventory, warranty, finance and telematics systems over SOAP, REST, SFTP, MQ, and flat files. Tekion needed standardized near real-time data sync without per-OEM custom builds.

### Solution

Built an OEM Integration Hub with standardized data contracts, protocol adapters, enterprise-grade security and near real-time sync to Tekion's platform.

### Tech stack

- Integration Hub
- SOAP / REST / SFTP / MQ
- Microservices
