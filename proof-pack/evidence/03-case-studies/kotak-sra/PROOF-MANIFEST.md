### Problem
1,800+ branch service request types choked turnaround time — 400 of them alone drove 80–90% of volume. High-value NEFT/RTGS approvals were still manual, creating authorization risk and delay.

### Solution
Automated the top 400 service requests on a scalable microservices stack and built a Transaction Authorization Service where branch users review and approve transfers in real time against a digital authorization matrix.

### Tech stack
- Java
- Spring Boot
- Microservices
- Authorization Matrix Engine
