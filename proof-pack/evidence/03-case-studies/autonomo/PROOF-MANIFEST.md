### Problem

Neighborhood retail is punished by checkout queues and staff overhead. The opportunity: a fully checkout-free store experience where customers tap in, grab items, and walk out.

### Solution

Built the complete Autonomo software stack - a computer-vision-powered autonomous store with mobile-app entry, TAPNGO contactless payments, and Telcred access control integration.

### Tech stack

- Computer Vision
- Mobile SDK
- Access Control APIs
