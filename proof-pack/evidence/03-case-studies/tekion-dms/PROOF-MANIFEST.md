### Problem
Automotive dealerships still run on legacy DMS platforms that silo sales, F&I, accounting, inventory and onboarding — with zero API access and painfully slow monthly reporting cycles.

### Solution
Built Tekion's cloud-native, API-driven DMS with integrated modules for sales, Finance & Insurance, accounting, contracting, inventory and dealer onboarding on an event-driven microservices backbone.

### Tech stack
- Microservices
